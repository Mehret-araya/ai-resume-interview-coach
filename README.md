# AI Resume + Interview Coach

AI-powered resume improvement and interview preparation platform.

## Core Features

- User authentication
- CV upload
- CV text extraction
- AI CV analysis
- AI CV rewriting
- CV editing
- Improved CV PDF generation
- Text-based mock interviews
- Voice-based mock interviews
- Speech-to-text
- AI interview evaluation
- Interview performance report
- Usage limits
- Stripe subscriptions


### Backend
